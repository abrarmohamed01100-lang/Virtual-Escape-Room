# Virtual Escape Room - Java OOP

A simple Java game to escape from a room by solving puzzles.

## How it Works
1. Program asks name -> you type name
2. Shows menu: 1.Solve Puzzle 2.Search Room 3.Hint 4.Status 5.Show Clues 6.Open Door
3. You must solve puzzles and search room to find 3 clues
4. Clues give you code 123
5. Enter code to escape

## Features
- 2 Puzzles (Word + Number)
- Search room for clues
- Hint system (-5 points)
- 3 tries only
- Save score to score.txt

## OOP I Used
- Encapsulation: private fields
- Abstract class: Puzzle
- Inheritance: WordPuzzle, NumberPuzzle extends Puzzle
- Polymorphism: check() different ways
- Composition: Game has Player + Room + puzzles
- File Handling: save and read scores

## How to Run
1. Open file Main.java in VS code and click Run
